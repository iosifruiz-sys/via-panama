# Vía Panamá

PWA personal para estudiar conceptos de tránsito en Panamá.

## MVP

- 17 tarjetas de vocabulario y repaso espaciado simplificado (no FSRS).
- Simulacro de 10 preguntas y repaso de errores.
- Progreso local en el navegador; sin registro.
- Interfaz en español, instalación en iPhone desde Safari.

**Importante:** Este material educativo no es una reproducción del examen oficial de Sertracen.

## Publicación

La rama `codex/mvp-initial` requiere revisión visual antes del merge. Tras aprobar y hacer merge, en Settings → Pages se selecciona GitHub Actions. En repositorios privados la disponibilidad de GitHub Pages depende del plan.
